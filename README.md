

# Simple Landing Page
![](img/webcss.png)
 
A single-page landing page for a web design service. Built with plain HTML and CSS, no frameworks or build tools.
 
## Sections
 
- **Home**: hero with headline, short description, and a call-to-action button
- **About**: short company introduction with an image
- **Services**: three service cards (Website Design, Fast & Reliable, Mobile Friendly)
- **Contact**: email, phone, and location details
- **WhatsApp button**: floating link fixed at the bottom-right corner
The navigation links in the header scroll to each section.
 
## Tech
 
- HTML5
- CSS3, with layout done entirely using Flexbox and Grid
